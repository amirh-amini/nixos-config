This file shows the goal and thus the reasoning behind decisions that I will make for configuring my NixOS setup. Goals that I shall follow to build my ideal setup for work, study, and leisure. Let us begin:

**Goal**: ideal workflow.

To achieve this goal, we need to first define the ideal workflow. For this, we can try to answer these questions first:

how an ideal workflow looks like:

* ideal workflow is liberating.
* allows you to spend your time exactly on what you want.
* It reduces extra cognitive load.
* It's smooth.
* It's deterministic, nothing unexpected will happen. Principle of least astonishment.
* It will allow you to achieve your maximum productivity.
* There isn't anything extra, if something exists, there is purpose for it.
* It's simple, no overcomplication.
* it's complete but not overly complicated.
* It's consistent.

ideal workflow should have these features:

* minimize maintenance
* minimize distraction
* focus your energy on the actual job. reduces extra work needed to do the job.

**concerns**:

from these, we can conclude having a stable and secure system is very important. recent supply chain attacks (shi-hulud types of attacks using npm or pypi, etc.) have been very damaging. I'm extremely concerned about this attack vector and I prioritize security.
