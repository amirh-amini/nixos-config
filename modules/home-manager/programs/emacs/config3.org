* PHASE 1 — CORE FOUNDATION
These are the packages and settings that must load first to establish a sane editing environment.  Everything else in this config depends on this foundation being in place.

** GCMH
[[https://github.com/emacsmirror/gcmh][GCMH]] (the Garbage Collector Magic Hack) adjusts the garbage collection threshold dynamically so that GC pauses happen during idle time rather than in the middle of your work.  This makes Emacs feel noticeably snappier.

#+begin_src emacs-lisp
(use-package gcmh
  :diminish
  :config
  (gcmh-mode 1))
#+end_src

** NO-LITTERING
By default, Emacs and its packages scatter data files and directories all over =user-emacs-directory=, leading to a lot of clutter.  [[https://github.com/emacscollective/no-littering][no-littering]] tidies things up by placing all of those files in sensible subdirectories.  It must be loaded early so that every subsequent package picks up the tidy locations.

#+begin_src emacs-lisp
(use-package no-littering
  :demand t)
#+end_src

** DIMINISH
This package implements hiding or abbreviation of the modeline displays (lighters) of minor-modes.  With this package installed, you can add =:diminish= to any use-package block to hide that particular mode in the modeline.  We load it early so the keyword works everywhere.

#+begin_src emacs-lisp
(use-package diminish)
#+end_src

** SANE DEFAULTS
The following settings are simple modes that are enabled (or disabled) so that Emacs functions more like you would expect a proper editor/IDE to function.

#+begin_src emacs-lisp
;; Short answers (y/n instead of yes/no)
(setq use-short-answers t)

;; Prevent custom.el from polluting our config
(setq custom-file (expand-file-name "custom.el" user-emacs-directory))
(when (file-exists-p custom-file)
  (load custom-file 'noerror 'nomessage))

;; You can select text and delete it by typing.
(delete-selection-mode 1)

;; Turn off the weird indenting that Emacs does by default.
(electric-indent-mode -1)
(setq-default tab-width 4
              indent-tabs-mode nil)

;; Display line numbers
(global-display-line-numbers-mode 1)
(setq display-line-numbers-type 'relative)  ;; relative line numbers for easier vim motions

;; Enable visual line mode (wrapping)
(global-visual-line-mode t)

;; Automatically show changes if the file has changed on disk
(global-auto-revert-mode t)
(setq global-auto-revert-non-file-buffers t)  ;; also applies to dired, ibuffer, etc.

;; Smooth scrolling with pixel precision (Emacs 29+)
(pixel-scroll-precision-mode 1)
(setq scroll-margin 8                  ;; keep 8 lines of context while scrolling
      scroll-conservatively 101        ;; avoid recentering the cursor
      scroll-up-aggressively 0.01
      scroll-down-aggressively 0.01)

;; Give buffers visiting same-name files unique names (e.g. foo/bar.el vs baz/bar.el)
(require 'uniquify)
(setq uniquify-buffer-name-style 'forward)

;; Uncomment the following line if line spacing needs adjusting.
(setq-default line-spacing 0.12)

;; No lockfiles (those .#file files get annoying)
(setq create-lockfiles nil)

;; Suppress native-comp warnings from cluttering your echo area
(setq native-comp-async-report-warnings-errors nil)

;; By default, Emacs requires you to hit ESC three times to escape the minibuffer.
(global-set-key [escape] 'keyboard-escape-quit)

;; Transparency (100 = opaque).  Try setting to 90 for slight transparency.
(add-to-list 'default-frame-alist '(alpha-background . 100))

;; Disable line numbers in certain modes where they don't make sense.
(dolist (mode '(org-mode-hook
                term-mode-hook
                vterm-mode-hook
                dashboard-mode-hook))
  (add-hook mode (lambda () (display-line-numbers-mode 0))))

#+end_src

(use-package evil
  :demand t
  :init      ;; tweak evil's configuration before loading it
  (setq evil-want-integration t       ;; This is optional since it's already set to t by default.
        evil-want-keybinding nil
        evil-want-C-u-scroll t        ;; use C-u to scroll up like in Vim
        evil-want-Y-yank-to-eol t     ;; Y yanks to end of line, not whole line
        evil-vsplit-window-right t
        evil-split-window-below t
        evil-undo-system 'undo-fu)    ;; use undo-fu for proper undo/redo
  :config
  (evil-mode 1)
  ;; Using RETURN to follow links in Org/Evil
  ;; Unmap keys in 'evil-maps if not done, (setq org-return-follows-link t) will not work
  (with-eval-after-load 'evil-maps
    (define-key evil-motion-state-map (kbd "SPC") nil)
    (define-key evil-motion-state-map (kbd "RET") nil)
    (define-key evil-motion-state-map (kbd "TAB") nil)))
#+end_src

* PHASE 3 — WRITING & VERSION CONTROL
Org-mode is the crown jewel of Emacs, and this phase sets it up for serious writing, note-taking, and task management.  We also bring in Magit for git and Jinx for spell checking.

** ORG MODE
Core org-mode settings.  This block configures TODO workflow, agenda, capture templates, source block editing, heading sizes, and keybindings.  Adjust =org-agenda-files= and capture file paths to match your setup.

*** Base Configuration
#+begin_src emacs-lisp
(use-package org
  :hook (org-mode . org-indent-mode)
  :config
  ;; Visual
  (setq org-ellipsis " ▾"                   ;; pretty ellipsis for collapsed headings
        org-hide-emphasis-markers t           ;; hide *bold* /italic/ markers
        org-startup-indented t
        org-startup-with-inline-images t
        org-image-actual-width '(300))

  ;; Source blocks
  (setq org-edit-src-content-indentation 0   ;; set src block indent to 0 instead of 2
        org-src-fontify-natively t
        org-src-preserve-indentation t
        org-src-tab-acts-natively t
        org-confirm-babel-evaluate nil)

  ;; Babel languages
  (org-babel-do-load-languages
   'org-babel-load-languages
   '((emacs-lisp . t)
     (python . t)
     (shell . t)))

  ;; Org-tempo: '<s' followed by TAB expands to a begin_src tag.
  ;; Other expansions: <q (quote), <e (example), <c (center), etc.
  (require 'org-tempo)

  ;; Setting RETURN key in org-mode to follow links
  (setq org-return-follows-link t)

  ;; TODO workflow
  (setq org-todo-keywords
        '((sequence "TODO(t)" "NEXT(n)" "IN-PROGRESS(i)" "|" "DONE(d)" "CANCELLED(c)")))
  (setq org-todo-keyword-faces
        '(("TODO"        . (:foreground "#ff6c6b" :weight bold))
          ("NEXT"        . (:foreground "#da8548" :weight bold))
          ("IN-PROGRESS" . (:foreground "#ECBE7B" :weight bold))
          ("DONE"        . (:foreground "#98be65" :weight bold))
          ("CANCELLED"   . (:foreground "#5B6268" :weight bold))))

  ;; Log when task completed
  (setq org-log-done 'time
        org-log-into-drawer t)

  ;; Agenda — adjust path to your org files
  (setq org-agenda-files '("~/org/"))
  (setq org-agenda-start-with-log-mode t
        org-agenda-window-setup 'current-window)

  ;; Capture templates — adjust file paths to your setup
  (setq org-capture-templates
        '(("t" "Todo" entry (file+headline "~/org/inbox.org" "Tasks")
           "* TODO %?\n  %U\n  %a\n  %i" :empty-lines 1)
          ("n" "Note" entry (file+headline "~/org/notes.org" "Notes")
           "* %?\n  %U\n" :empty-lines 1)
          ("j" "Journal" entry (file+datetree "~/org/journal.org")
           "* %?\n  %U\n" :empty-lines 1)
          ("m" "Meeting" entry (file+headline "~/org/meetings.org" "Meetings")
           "* %? :meeting:\n  %U\n" :empty-lines 1)))

  ;; Refile targets
  (setq org-refile-targets '((nil :maxlevel . 3)
                             (org-agenda-files :maxlevel . 3)))
  (setq org-refile-use-outline-path 'file
        org-outline-path-complete-in-steps nil))
#+end_src

** PERSP-MODE

    "TAB" '(:ignore t :wk "Workspaces")

    "TAB n" '(persp-next :wk "Next workspace")
    "TAB p" '(persp-prev :wk "Previous workspace")
    "TAB d" '(persp-kill :wk "Delete workspace")
    "TAB r" '(persp-rename :wk "Rename workspace")
