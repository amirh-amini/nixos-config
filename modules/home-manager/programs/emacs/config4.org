* PHASE 1 — CORE FOUNDATION
The packages and settings in this section form the bedrock of the entire config.  Everything else depends on these being loaded first, so they must come before anything else.

** GCMH
[[https://github.com/emacsmirror/gcmh][GCMH]] (Garbage Collector Magic Hack) optimizes Emacs' garbage collection.  Instead of collecting garbage constantly while you type, it defers GC to idle time.  This makes Emacs feel noticeably snappier.

#+begin_src emacs-lisp
(use-package gcmh
  :diminish
  :config
  (gcmh-mode 1))
#+end_src

** No-Littering
[[https://github.com/emacscollective/no-littering][No-littering]] keeps your =~/.config/emacs/= directory clean by redirecting package files into standard data and config subdirectories.  It needs to load early so every package installed after it benefits from the tidy file placement.

#+begin_src emacs-lisp
(use-package no-littering
  :demand t)
#+end_src

** Diminish
This package implements hiding or abbreviation of the modeline displays (lighters) of minor-modes.  With this package installed, you can add =:diminish= to any use-package block to hide that particular mode in the modeline.  Must be loaded early so the =:diminish= keyword works in all subsequent =use-package= blocks.

#+begin_src emacs-lisp
(use-package diminish)
#+end_src

** Sane Defaults
The following settings are simple modes that are enabled (or disabled) so that Emacs functions more like you would expect a proper editor/IDE to function.

#+begin_src emacs-lisp
;; Short answers (y/n instead of yes/no)
(setq use-short-answers t)

;; Prevent custom.el from polluting our config.
;; Emacs will write customization data to this separate file instead.
(setq custom-file (expand-file-name "custom.el" user-emacs-directory))
(when (file-exists-p custom-file)
  (load custom-file 'noerror 'nomessage))

(delete-selection-mode 1)    ;; You can select text and delete it by typing.
(electric-indent-mode -1)    ;; Turn off the weird indenting that Emacs does by default.
(setq-default tab-width 4
              indent-tabs-mode nil)

;; Display line numbers
(global-display-line-numbers-mode 1)
(setq display-line-numbers-type 'relative)

(global-visual-line-mode t)  ;; Enable truncated lines
(global-auto-revert-mode t)  ;; Automatically show changes if the file has changed
(setq global-auto-revert-non-file-buffers t) ;; Also auto-revert non-file buffers (dired, etc.)

;; Smooth scrolling — pixel-scroll-precision-mode was added in Emacs 29.
(pixel-scroll-precision-mode 1)
(setq scroll-margin 8
      scroll-conservatively 101
      scroll-up-aggressively 0.01
      scroll-down-aggressively 0.01)

;; Unique buffer names — when two files share a name, show their directory path.
(require 'uniquify)
(setq uniquify-buffer-name-style 'forward)

;; Uncomment the following line if line spacing needs adjusting.
(setq-default line-spacing 0.12)

(setq create-lockfiles nil)  ;; No .#lockfiles cluttering your directories

;; Suppress native-comp warnings — they are mostly noise.
(setq native-comp-async-report-warnings-errors nil)

;; By default, Emacs requires you to hit ESC three times to escape quit the minibuffer.
(global-set-key [escape] 'keyboard-escape-quit)

;; With Emacs version 29, true transparency has been added.
;; Set alpha to '90' for slight transparency, or '0' for fully transparent.
(add-to-list 'default-frame-alist '(alpha-background . 100))

;; Disable line numbers in certain modes where they don't make sense.
(dolist (mode '(org-mode-hook
                term-mode-hook
                vterm-mode-hook
                dashboard-mode-hook))
  (add-hook mode (lambda () (display-line-numbers-mode 0))))
#+end_src

  :slant 'italic)

  :slant 'italic)

(add-to-list 'default-frame-alist '(font . "JetBrainsMono Nerd Font-11"))

** Evil Mode
[[https://github.com/emacs-evil/evil][Evil]] is an extensible vi/vim layer for Emacs.  Because...let's face it.  The Vim keybindings are just plain better.  We set the undo system to =undo-fu= for proper vim-like undo/redo.

#+begin_src emacs-lisp
(use-package evil
  :demand t
  :init      ;; Tweak evil's configuration before loading it
  (setq evil-want-integration t  ;; This is optional since it's already set to t by default.
        evil-want-keybinding nil
        evil-want-C-u-scroll t
        evil-want-Y-yank-to-eol t
        evil-vsplit-window-right t
        evil-split-window-below t
        evil-undo-system 'undo-fu)  ;; Use undo-fu for proper undo/redo
  :config
  (evil-mode 1)
  ;; Using RETURN to follow links in Org/Evil
  ;; Unmap keys in 'evil-maps if not done, (setq org-return-follows-link t) will not work
  (with-eval-after-load 'evil-maps
    (define-key evil-motion-state-map (kbd "SPC") nil)
    (define-key evil-motion-state-map (kbd "RET") nil)
    (define-key evil-motion-state-map (kbd "TAB") nil)))
#+end_src

* PHASE 2 — SEARCH, HELP AND BUILT-IN QOL
This phase brings in a modern completion framework (Vertico + Orderless + Consult + Embark) and upgrades built-in help.  These packages transform how you interact with minibuffer prompts, search for files, and look up documentation.

** Saveplace
Saveplace remembers where the cursor was in each file across sessions.  When you re-open a file, you'll be right where you left off.

#+begin_src emacs-lisp
(use-package saveplace
  :config
  (save-place-mode 1))
#+end_src

** Savehist
Savehist persists your minibuffer history (M-x commands, search strings, etc.) across Emacs sessions.  This means your most-used commands float to the top.

#+begin_src emacs-lisp
(use-package savehist
  :config
  (setq history-length 25)
  (savehist-mode 1))
#+end_src

** Recentf
Recentf tracks recently visited files so you can quickly jump back to them.  We configure it here but the actual keybinding (=SPC f r=) comes from Consult below.

#+begin_src emacs-lisp
(use-package recentf

** Vertico
[[https://github.com/minad/vertico][Vertico]] provides a performant and minimalistic vertical completion UI for the minibuffer.  Think of it as a lightweight alternative to Ivy or Helm.

#+begin_src emacs-lisp
(use-package vertico

  :config

** Orderless
[[https://github.com/oantolin/orderless][Orderless]] provides an orderless completion style that divides the pattern into space-separated components and matches candidates that match all of the components in any order.  This means you can type "buffer switch" or "switch buffer" and get the same results.

#+begin_src emacs-lisp
(use-package orderless
  :config
  (setq completion-styles '(orderless basic)
        completion-category-defaults nil
        completion-category-overrides
        '((file (styles partial-completion)))))
#+end_src

* PHASE 3 — WRITING AND VERSION CONTROL
This phase configures Org mode (the crown jewel of Emacs), Git integration via Magit, and spell checking.  If you use Emacs for writing, taking notes, or managing tasks, this is where the magic happens.

** Org Base Configuration
Core org-mode settings.  This block configures TODO workflow, agenda, capture templates, source block editing, heading sizes, and keybindings.  Adjust =org-agenda-files= and capture file paths to match your setup.

#+begin_src emacs-lisp
(use-package org
  :hook (org-mode . org-indent-mode)
  :config
  ;; Visual settings
  (setq org-ellipsis " ▾"
        org-hide-emphasis-markers t
        org-startup-indented t
        org-startup-with-inline-images t
        org-image-actual-width '(300))

  ;; Source block settings
  (setq org-edit-src-content-indentation 0  ;; Set src block indent to 0 instead of 2
        org-src-fontify-natively t
        org-src-preserve-indentation t
        org-src-tab-acts-natively t
        org-confirm-babel-evaluate nil)

  ;; Babel languages — add more as needed
  (org-babel-do-load-languages
   'org-babel-load-languages
   '((emacs-lisp . t)
     (python . t)
     (shell . t)))

  ;; Org-tempo is not a separate package but a module within org that can be enabled.
  ;; Org-tempo allows for '<s' followed by TAB to expand to a begin_src tag.
  ;; Other expansions available include:
  ;;
  ;; | Typing the below + TAB | Expands to ...                          |
  ;; |------------------------+-----------------------------------------|
  ;; | <a                     | '#+BEGIN_EXPORT ascii' … '#+END_EXPORT  |
  ;; | <c                     | '#+BEGIN_CENTER' … '#+END_CENTER'       |
  ;; | <C                     | '#+BEGIN_COMMENT' … '#+END_COMMENT'     |
  ;; | <e                     | '#+BEGIN_EXAMPLE' … '#+END_EXAMPLE'     |
  ;; | <E                     | '#+BEGIN_EXPORT' … '#+END_EXPORT'       |
  ;; | <h                     | '#+BEGIN_EXPORT html' … '#+END_EXPORT'  |
  ;; | <l                     | '#+BEGIN_EXPORT latex' … '#+END_EXPORT' |
  ;; | <q                     | '#+BEGIN_QUOTE' … '#+END_QUOTE'         |
  ;; | <s                     | '#+BEGIN_SRC' … '#+END_SRC'             |
  ;; | <v                     | '#+BEGIN_VERSE' … '#+END_VERSE'         |
  (require 'org-tempo)

  ;; Setting RETURN key in org-mode to follow links
  (setq org-return-follows-link t)

  ;; TODO workflow — customize these states to match how you work
  (setq org-todo-keywords
        '((sequence "TODO(t)" "NEXT(n)" "IN-PROGRESS(i)" "|" "DONE(d)" "CANCELLED(c)")))
  (setq org-todo-keyword-faces
        '(("TODO" . (:foreground "#ff6c6b" :weight bold))
          ("NEXT" . (:foreground "#da8548" :weight bold))
          ("IN-PROGRESS" . (:foreground "#ECBE7B" :weight bold))
          ("DONE" . (:foreground "#98be65" :weight bold))
          ("CANCELLED" . (:foreground "#5B6268" :weight bold))))

  ;; Log when task completed
  (setq org-log-done 'time
        org-log-into-drawer t)

  ;; Agenda — adjust path to your org files
  (setq org-agenda-files '("~/org/"))
  (setq org-agenda-start-with-log-mode t
        org-agenda-window-setup 'current-window)

  ;; Capture templates — adjust file paths to your setup
  (setq org-capture-templates
        '(("t" "Todo" entry (file+headline "~/org/inbox.org" "Tasks")
           "* TODO %?\n  %U\n  %a\n  %i" :empty-lines 1)
          ("n" "Note" entry (file+headline "~/org/notes.org" "Notes")
           "* %?\n  %U\n" :empty-lines 1)
          ("j" "Journal" entry (file+datetree "~/org/journal.org")
           "* %?\n  %U\n" :empty-lines 1)
          ("m" "Meeting" entry (file+headline "~/org/meetings.org" "Meetings")
           "* %? :meeting:\n  %U\n" :empty-lines 1)))

  ;; Refile targets
  (setq org-refile-targets '((nil :maxlevel . 3)

** Vterm Toggle
[[https://github.com/jixiuf/vterm-toggle][Vterm-toggle]] toggles between the vterm buffer and whatever buffer you are editing.  The terminal appears as a popup at the bottom of the frame.

#+begin_src emacs-lisp
(use-package vterm-toggle
  :after vterm
  :config
  ;; When running programs in Vterm and in 'normal' mode, make sure that ESC
  ;; kills the program as it would in most standard terminal programs.
  (evil-define-key 'normal vterm-mode-map (kbd "<escape>") 'vterm--self-insert)
  (setq vterm-toggle-fullscreen-p nil)
  (setq vterm-toggle-scope 'project)
  (add-to-list 'display-buffer-alist
               '((lambda (buffer-or-name _)
                     (let ((buffer (get-buffer buffer-or-name)))
                       (with-current-buffer buffer
                         (or (equal major-mode 'vterm-mode)
                             (string-prefix-p vterm-buffer-name (buffer-name buffer))))))
                  (display-buffer-reuse-window display-buffer-at-bottom)
                  ;;(display-buffer-reuse-window display-buffer-in-direction)
                  ;;display-buffer-in-direction/direction/dedicated is added in emacs27
                  ;;(direction . bottom)
                  ;;(dedicated . t) ;dedicated is supported in emacs27
                  (reusable-frames . visible)
                  (window-height . 0.4)))
  (my/leader-def
    "o v" '(vterm-toggle :wk "Toggle vterm")
    "o V" '(vterm-other-window :wk "Vterm other window")))
