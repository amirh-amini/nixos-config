* Phase 1 — Core Foundation

** gcmh

#+begin_src emacs-lisp

#+end_src

** no-littering

Must load early so other packages write their data to tidy locations.

#+begin_src emacs-lisp
  (use-package no-littering
    :demand t)
#+end_src

** evil

=evil-want-keybinding= must be nil before evil loads so that
evil-collection provides bindings for non-core modes instead.

#+begin_src emacs-lisp
  (use-package evil
    :demand t
    :init
    (setq evil-want-integration t
          evil-want-keybinding nil
          evil-want-C-u-scroll t
          evil-want-Y-yank-to-eol t
          evil-undo-system 'undo-fu)
    :config
    (evil-mode 1))
#+end_src

** evil-collection

#+begin_src emacs-lisp
  (use-package evil-collection
    :after evil
    :config
    (evil-collection-init))
#+end_src

** undo-fu

No config needed — evil references it via =evil-undo-system=.

#+begin_src emacs-lisp
  (use-package undo-fu)
#+end_src

** general

Creates the leader key definer used throughout the rest of the config.

#+begin_src emacs-lisp
  (use-package general
    :demand t
    :config
    (general-create-definer my/leader-def
      :keymaps 'override
      :states '(normal insert visual emacs)
      :prefix "SPC"
      :global-prefix "M-SPC"))
#+end_src
